## Схема базы данных

- `schema.sql`: скрипт для PostgreSQL 16. Скрипт создаёт 13 таблиц, 18 внешних ключей и 3 индекса. Поле `staff.role` принимает значения «сотрудник» и «администратор».
- `db_schema.dbml`: та же схема в формате DBML для dbdiagram.io.

Как проверить скрипт:

```
createdb predzakaz_test
psql -d predzakaz_test -v ON_ERROR_STOP=1 -f models/schema.sql
```
