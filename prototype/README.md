## Как собрать прототип в Figma

1. Создайте файл Design в Figma.
2. Перетащите 8 файлов PNG из папки `screens` на холст.
3. Выделите каждую картинку и нажмите Ctrl+Alt+G. Картинка станет фреймом. Дайте фрейму имя экрана из таблицы выше.
4. Нарисуйте прозрачный прямоугольник (заливка 0 %) поверх каждой кнопки. Координаты даны в таблице ниже.
5. Откройте вкладку Prototype. Соедините каждый прямоугольник с фреймом из столбца «Куда ведёт». Взаимодействие: On click → Navigate to.
6. Сделайте фрейм «Э-1 Меню дня» начальной точкой (Flow starting point).
7. Откройте доступ: Share prototype → Anyone with the link → can view. Откройте ссылку в окне инкогнито. Ссылка должна открываться без входа.
8. Запишите ссылку в начало этого файла, в README репозитория и в отчёт.
