## BUG-001 Кнопка «+» в меню не добавляет блюдо

| Поле | Значение |
|---|---|
| Где | Прототип, версия 2, Э-1 «Меню на сегодня» |
| Шаги | 1) Открыть Э-1; 2) нажать «+» у позиции «Лагман» |
| Ожидаемый результат | Лагман в корзине; кнопка корзины: 3 позиции, 49 000 сум |
| Фактический результат | Кнопка «+» не меняется; корзина: 2 позиции, 27 000 сум |
| Серьёзность · приоритет | Высокая · высокий |
| Связь | US-02, крит. 1 · TC-005 |
| Снимок экрана | screenshots/bug_001.png |
| Ответ | Принят: Студент не может собрать свой заказ: в меню работают только две заранее выбранные позиции |
| Статус | Закрыт: исправлен в версии 2.1, проверен в прогоне 2 |
